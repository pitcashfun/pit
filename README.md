## How it works

1. Deploy `PitStop`. Fee recipient on LetsCash = that address.
2. Mint `$PIT` at 5%. 0.3% pad, 4.7% into the box.
3. `stop(compound)` — first 20 cars, one per wallet per stint.
4. 3 minutes. Anyone `flag()`. 1% bounty. Rest split by weight.

Soft ×1. Medium ×2. Hard ×3. No merkle. No private keeper.

Addresses empty until Remix + LetsCash. Never invented here.
